# SDCC Z80 ROM Project

This is a multipurpose subproject for building Zephyr-80 ROM images from
Z80 assembly sources using the SDCC toolset. Each ROM build is selected by
the `TARGET` name, which maps to a source file in `src/` and output files in
`build/`.

## Structure

- `src/`: ROM source assembly files (`<target>.s`)
- `build/`: Generated build files, created automatically
- `Makefile`: Shared build script for all ROM targets

## Building

The Makefile builds `src/$(TARGET).s` into `build/$(TARGET).*`.

To build the default target:

```bash
make
```

By default, `TARGET` is `main`, so this generates `build/main.ihx`.

To build a specific ROM source, pass the target name without the `.s`
extension. For example, to build `src/firstboot.s`:

```bash
make TARGET=firstboot
```

This will generate `build/firstboot.ihx`, an Intel HEX file suitable for
flashing to ROM or loading into an emulator.

To generate a raw ROM binary suitable for MAME, run:

```bash
make TARGET=firstboot bin
```

This will create `build/firstboot.bin`. Use the same `TARGET` value for
`make`, `make bin`, and related build commands so all generated files refer to
the same ROM. Raw binary ROM files are padded to 8 KiB (`0x2000` bytes) with
`0xff` bytes by default.

## Requirements

- SDCC (Small Device C Compiler) installed with Z80 support
- GNU `objcopy` (from `binutils`)
- Make

## Ubuntu install

On Ubuntu, install the required packages with:

```bash
sudo apt update
sudo apt install sdcc binutils make
```

If `objcopy` is not already available, it is provided by the `binutils` package.

## Usage

Add or edit ROM source files in `src/`, using one source file per ROM target.
The source filename determines the build target name:

- `src/firstboot.s` is built with `make TARGET=firstboot`
- `src/diagnostics.s` would be built with `make TARGET=diagnostics`

The code starts at address 0x0000.

Run `make clean` to clean build artifacts.

## Output

All generated files are placed in the `build/` directory:

- `build/<target>.ihx`: Intel HEX file
- `build/<target>.bin`: 8 KiB raw ROM binary, generated by `make TARGET=<target> bin`
- `build/<target>.lst`: Listing file
- `build/<target>.sym`: Symbol file
- `build/<target>.rel`: Relocatable object file
