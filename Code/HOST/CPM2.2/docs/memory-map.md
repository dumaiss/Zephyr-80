Generated by `tools/generate_memory_docs.py` from `build/firmware.lst`, `build/layout.manifest`, and image artifacts.

## Address Space Overview

| Range | Use | Notes |
|---|---|---|
| `0000h-00FFh` | Page zero and default DMA area | Runtime code installs `JP WBOOT` at `0000h` and `JP FBASE` at `0005h`; default DMA/command tail starts at `0080h`. |
| `0100h-BFFFh` | CP/M banked TPA | Runnable programs may use this banked low-memory range. |
| `C000h-C3FFh` | CP/M protected TPA | Non-banked marker range is `C000h-CFFFh`; the effective TPA portion stops before `CBASE`. |
| `C400h-CBABh` | CP/M CCP | `CBASE` is `C400h`. |
| `CC06h-D9FFh` | CP/M BDOS and state | `FBASE` is `CC06h` in the current assembled image. |
| `DA00h-E704h` | Zephyr BIOS code | BIOS jump table, boot, console, storage facade, RAM disk backend, NMI support, banking, and launch routines. |
| `E705h-F5FFh` | Reserved high BIOS/code space | Available within the current firmware map for later BIOS code or validation reservations. |
| `F600h-F77Fh` | Protected BIOS scratch buffers | `MOVE_BUFFER` is at `F600h`; `RAMDISK_DIRBUF` is at `F700h`. |
| `F900h-F96Ah` | BIOS runtime state | Current bank, DMA address, console counters, and banking state. |
| `F880h-F9FFh` | Protected firmware stack and work window | Stack top is `FFF0h`; stack guard is `F880h`. |

## Validation Notes

- CP/M drive A is backed by RAM banks 2-7 across `0000h-BFFFh` in each bank.
- The RAM disk seed image is copied from ROM to RAM during boot shadow-copy, then writes mutate RAM only.
- The protected TPA marker is `C000h-CFFFh`; for this build, the application-usable protected TPA subrange is `C000h-C3FFh` because `CBASE` starts at `C400h`.
- WBOOT restores the CCP range `C400h-CC05h` from ROM page 0 using `ROM_VISIBLE_BANK0` (`00h`) before returning to `CCP_CLEARBUF_ENTRY`.
- `CBIOS_BASE` is `DA00h`; CBIOS layout constants are derived from this base.
- `LAUNCH` code resides at `E6AEh`, inside protected high BIOS memory.
- `WBOOT` resident code starts at `DAF6h`, inside protected high BIOS memory.
- `ZBIOS_EXT_BASE` is at `DA33h` and exposes `MOVE`, `XMOVE`, `SELMEM`, `SETBNK`, and `LAUNCH`.
- The final bit-swapped image is `build/zephyr80.bin`.
